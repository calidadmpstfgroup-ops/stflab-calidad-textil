# STFLab 2.0 - Sistema de Control de Calidad Textil, Compras y Patronaje

Este es el repositorio completo del sistema **STFLab 2.0**, desarrollado con React, TypeScript, Tailwind CSS y Vite.

## 🚀 Requisitos Previos
- Node.js (versión 18 o superior)
- npm o yarn

## 🛠️ Instalación y Ejecución en Otro Sistema
1. Descarga o descomprime este proyecto en el nuevo sistema.
2. Abre una terminal dentro de la carpeta del proyecto.
3. Instala las dependencias:
   \\\ash
   npm install
   \\\Rồi
4. Inicia el servidor de desarrollo:
   \\\ash
   npm run dev
